# Sony zoom explorer

A notebook that shows which zoom values come straight from the camera and which
the sony-remote module computes. It reads the camera's raw property table next
to `get_zoom`, plots two independent camera properties against each other, and
pulls the relevant module code from this checkout. Run it from this directory:

    cd notebooks/zoom_explorer
    uv venv --python 3.12 .venv && uv pip install --python .venv/bin/python -r requirements.txt
    export VIAM_API_KEY=...  VIAM_API_KEY_ID=...    # omit to replay snapshot.json
    .venv/bin/jupyter lab sony_zoom_explorer.ipynb

The notebook is generated by `build_notebook.py`; edit that and re-run it.
Nothing moves the lens unless `MOVE_LENS = True` (sections 5 and 7).
